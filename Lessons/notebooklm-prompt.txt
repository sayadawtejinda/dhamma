Google NotebookLM ကို ဒီစာကို ကူးပြီး ပေးပါ (မူရင်းစာအုပ်တွေ/ဖိုင်တွေကို Source အဖြစ် ထည့်ပြီးမှ)
==============================================================================================

ပုံစံ ၁ (အကောင်းဆုံး): ဆောင်းပါးတစ်ပုဒ်ချင်းစီကို Markdown (.md) အဖြစ် ထုတ်ခိုင်းမယ်
----------------------------------------------------------------------------------------
အောက်ပါ စာကို NotebookLM ရဲ့ chat box ထဲ ကူးထည့်ပါ။ [   ] ထဲက စာကို ပြောင်းပါ။

    [အကြောင်းအရာ - ဥပမာ "စေတသိက် ၅၂ ပါး"] ကို ကျောင်းသား၊ ကျောင်းသူတွေ သင်ယူနိုင်ဖို့ [၁၀] ပုဒ်ပါတဲ့ ဆောင်းပါးတွဲအဖြစ် ရေးပေးပါ။
    ဆောင်းပါးတစ်ပုဒ်စီကို သီးခြားစီ ရေးပါ။ စည်းမျဉ်းတွေက ဒီလိုပါ -
    1. ဆောင်းပါးတစ်ပုဒ်ရဲ့ ပထမစာကြောင်းက  "# ဆောင်းပါး (၁) - ခေါင်းစဉ်"  လို့ စပါစေ (# တစ်လုံးတည်း၊ နောက်မှာ space)။
    2. ဆောင်းပါးထဲက အပိုင်းခေါင်းစဉ်တွေကို  "## ၁။ ..."  လို့ ရေးပါ (# နှစ်လုံး)။
    3. ဆောင်းပါးတစ်ပုဒ်ကို မြန်မာစာလုံး ၄၀၀၀ ကနေ ၇၀၀၀ ကြားထားပါ။ အပိုင်း ၄ ကနေ ၆ ပိုင်း ထားပါ။
    4. စာပိုဒ်တွေနဲ့ အချက်ပြ စာရင်းတွေ အဓိကသုံးပါ။ ဇယားက လိုအပ်မှ တစ်ခုနှစ်ခုပါလည်း ရပါတယ် (စာလိုင်းအဖြစ် ပြောင်းပေးပါတယ်)။
    5. မြန်မာလိုပဲ ရေးပါ။ ကလေးတွေ နားလည်လွယ်တဲ့ စကားလုံးတွေ သုံးပါ။ ပါဠိစကားလုံးကို အနည်းဆုံးသုံးပြီး သုံးရင် အဓိပ္ပာယ် ရှင်းပြပါ။
    6. ဆောင်းပါးတွေကြားမှာ ဘာမှ မရေးပါနဲ့ ("ဟုတ်ကဲ့၊ ဒီမှာပါ" စတဲ့ စကားတွေ မလိုပါ)။

ပြီးရင် NotebookLM က ထုတ်ပေးတဲ့ ဆောင်းပါးတစ်ပုဒ်စီကို .md ဖိုင်အဖြစ် သိမ်းပါ (Save / Download as Markdown)။ ဖိုင်နာမည်ကို
article-1-xxx.md ၊ article-2-xxx.md ... လို့ နံပါတ်အစဉ်နဲ့ ပေးထားပါ။ နံပါတ်က အစဉ်ကို ဆုံးဖြတ်ပါတယ်။


ပုံစံ ၂: chat box က စာပြန်ပေးတာကို ကူးပြီး .txt ဖိုင်လုပ်မယ်
----------------------------------------------------------
NotebookLM က ဖိုင်မထုတ်ပေးဘဲ chat ထဲမှာ စာအဖြစ်ပဲ ပြန်ရင် အဲဒီစာအားလုံးကို ကူးပြီး Notepad ထဲ paste၊ ဖိုင်ကို  something.txt  လို့ သိမ်းပါ
(Save As မှာ Encoding ကို UTF-8 ရွေးပါ)။ ဆောင်းပါးတွေကို ခွဲဖို့ အောက်ပါတစ်ခုခု ရှိရပါမယ် -

    ဆောင်းပါး (၁) - ခေါင်းစဉ်          <- ဒီလိုစာကြောင်း (စကားလုံး "ဆောင်းပါး" / "သင်ခန်းစာ" / "Article" / "Lesson" + နံပါတ်)
    ဒါမှမဟုတ်  === ခေါင်းစဉ် ===         <- လိုချင်ရင် ဒီပုံစံလည်း ရပါတယ်

NotebookLM ကို ဒီလို ပြောပါ - "ဆောင်းပါးတစ်ပုဒ်စီရဲ့ ပထမစာကြောင်းကို  ဆောင်းပါး (၁) - ခေါင်းစဉ်  ပုံစံနဲ့ စပါ"။

နမူနာဖိုင်များ (ဒီဖိုဒါထဲမှာ ရှိပါတယ်) -
    sample-md.md         ပုံစံ ၁ ရဲ့ နမူနာ
    sample-chat.txt      ပုံစံ ၂ ရဲ့ နမူနာ (ဆောင်းပါး (၁) - ... နဲ့ စ)
    sample-equals.txt    === ခေါင်းစဉ် === နဲ့ စတဲ့ နမူနာ

ဘယ်ပုံစံမှ မကိုက်ရင် -
