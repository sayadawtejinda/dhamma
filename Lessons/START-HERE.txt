=== အဆင့် ၁။ စာသားကို ရအောင်လုပ် (Google NotebookLM) ======================================

 ၁.၁ notebooklm-prompt.txt ထဲက စာကို NotebookLM မှာ ကူးပေးပါ။ အဲဒီမှာ ရေးထားတဲ့ ပုံစံနှစ်မျိုးရှိတယ်။
      ပုံစံ ၁ (အကောင်းဆုံး) - ဆောင်းပါးတစ်ပုဒ်စီကို .md ဖိုင်အဖြစ် သိမ်းပါ။ နာမည်ကို နံပါတ်ထည့်ပါ -
                article-1-xxx.md ၊ article-2-xxx.md ... (article-2 က article-10 ရှေ့ကပါ)
      ပုံစံ ၂ - chat ကပြန်ပေးတဲ့ စာကို အကုန်ကူး၊ Notepad မှာ paste၊ ဖိုင်ကို .txt (UTF-8) လို့ သိမ်းပါ။ ဆောင်းပါးတစ်ပုဒ်စီ
                "ဆောင်းပါး (၁) - ခေါင်းစဉ်" လို စာကြောင်းနဲ့ စရပါမယ်။
 ၁.၂ ဖိုင်တွေကို Downloads ထဲ ထားပါ။
 ၁.၃ ဆောင်းပါး ၁ ပုဒ် = သင်ခန်းစာ ၁ ခု။ ရှည်လွန်းရင် (စာလုံး ၉၀၀၀ ကျော်) ခွဲပေးဖို့ NotebookLM ကို ပြောပါ။
 ၁.၄ ဘယ်ပုံစံမှ မကိုက်ဘူး၊ ဖိုင်ဖတ်လို့ မရဘူးဆိုရင် - ဒီဖိုင်ကို ကျွန်တော် (Claude) ဆီ ပို့ပါ၊ ကိုက်အောင် ပြင်ပေးပါမယ်။

 စာသားကနေ သင်ခန်းစာဖိုင် (.json) လုပ်ချင်ရင် (Canvas ကို မသုံးဘဲ Gemini key နဲ့ လုပ်မယ်ဆိုရင်ပဲ) lessons.bat ရဲ့ 1 ကို သုံးနိုင်ပါတယ်။
 Canvas ထဲမှာ ဖိုင်ကို တိုက်ရိုက်တင်လို့ရလို့ အဲဒါမလိုပါဘူး။


=== အဆင့် ၂။ ပုံတွေ ===================================================================

 ၂.၁ Gemini ကို သင်ခန်းစာတစ်ခုစီအတွက် ပုံချပ် (ပုံ ၆ ပုံပါတဲ့ တစ်ပုံ) ထုတ်ခိုင်းပါ။ ထုတ်ပြီးရင် Downloads ထဲ သိမ်းပါ။
      ဖိုင်နာမည်ကို သင်ခန်းစာ နံပါတ်နဲ့ ပြောင်းပါ -  01.jpg  02.jpg  03.jpg ... (အရေးကြီး၊ နံပါတ်အတိုင်း ပုံရွေးပါလိမ့်မယ်)
 ၂.၂ lessons.bat ကို နှစ်ချက်နှိပ်ပါ (ဒီဖိုဒါထဲ Open-Lessons-Menu.bat နဲ့လည်း ရတယ်)။ မီနူးမှာ  2  ကို နှိပ်ပါ။
        - ချပ်တစ်ချပ်ချင်း ပုံကို ပြပါမယ်။ ပုံထဲမှာ အနီရောင်စက်ဝိုင်းနဲ့ နံပါတ် ၁ ကနေ ၆ ရှိပါတယ်။
        - "ဘယ်ပုံကို ဖယ်မလဲ" မေးရင် မလိုတဲ့ပုံ၏ နံပါတ်ကို ရိုက်ပါ (ပုံ ၅ ပုံ ပဲ သင်ခန်းစာတစ်ခုကို သုံးပါတယ်)။ အကြံ - ၆ ပုံမြောက်က အနှစ်ချုပ်ဖြစ်တတ်လို့ ၆ ကို ဖယ်ပါ။
        - "Just press Enter to cut it as 3x2" လို့ မေးရင် Enter တစ်ချက်နှိပ်ပါ (ချပ်က ၃ ပုံဘေးတိုက်၊ ၂ တန်း ဖြစ်တာများတယ်)။ ၂x၃ ဆိုရင် 2x3 လို့ ရိုက်ပါ။
        - ပုံတွေကို  L01-P1 ... L01-P5  (သင်ခန်းစာ ၁ ရဲ့ ပုံ ၁ ကနေ ၅) နာမည်နဲ့  Downloads\lesson-pictures  ထဲ သိမ်းပေးပါတယ်။ မူရင်းချပ်ကို မဖျက်ပါ (sheets ထဲ ရွှေ့ပါတယ်)။
 ၂.၃ ပုံဖြတ်လို့ မရတဲ့ အခြေအနေတွေ -
        က) ချပ်ထဲက ပုံတွေ အရွယ်မတူလို့ ဖြတ်ချက် မမှန်ဘူး (စာလုံးတွေ ပြတ်နေတယ်၊ ပုံတစ်ခုက ကျယ်ပြီး ကျန်တာ ကျဉ်း) -
            ဖြတ်ရင်ထွက်တဲ့ preview ကို ကြည့်ပါ။ မမှန်ရင်  s  ရိုက်ပြီး ကျော်ပါ၊ ပြီးရင် အောက်က (ခ) သို့ (ဂ) ကို သုံးပါ။
        ခ) ကိုယ်တိုင် ဖြတ်မယ် - Windows မှာ  Win + Shift + S  နှိပ်ပြီး ပုံတစ်ပုံစီ ဖြတ်၊ သိမ်းပါ။
            Downloads\lesson-pictures ထဲမှာ သင်ခန်းစာနံပါတ်နဲ့ ဖိုဒါဆောက်ပါ (ဥပမာ  04  ဒါမှမဟုတ်  L04  ဒါမှမဟုတ်  lesson 4)။
            ပုံ ၅ ပုံကို အဲဒီထဲ ထည့်ပါ။ ဖိုင်နာမည် အစဉ်အတိုင်း (screenshot နာမည်မှာ အချိန်ပါလို့ ရိုက်တဲ့အစဉ်) ပထမပုံက P1 ပါ။ ကုဒ်က နားလည်ပါတယ်။
            ချပ်ခွဲပြီးသား သင်ခန်းစာတွေနဲ့ ရောနှောသုံးလို့ရပါတယ်။
        ဂ) ကျွန်တော် (Claude) ကို ချပ်ဖိုင်ပို့ပါ။ ပုံတစ်ပုံစီ တိတိကျကျ ဖြတ်ပြီး L04-P1... နာမည်နဲ့ ထည့်ပေးပါမယ် (ဒီလိုပဲ ဆောင်းပါး ၁ နဲ့ ၄ မှာ လုပ်ခဲ့တာ)။
        ဃ) Gemini ကို ပုံတစ်ပုံစီ ထုတ်ခိုင်းမယ် - lessons.bat ရဲ့  3  (name-pictures)။ ပုံတစ်ပုံထုတ်တိုင်း Enter နှိပ်ရင် နာမည်ပေးပါတယ်။
            (အဲဒါအတွက် မြန်မာစာ lessons file ကို  lessons.bat 1 နဲ့ ထုတ်ပြီး "picture plan" မေးရင် y ရွေးရပါမယ်။)
 ၂.၄ ပုံတွေကို GitHub ပေါ် တင်ဖို့ -
        lessons.bat မှာ  4  (Upload the pictures to GitHub)  ကို နှိပ်ပါ။
        - SmartStudy လား Abhidhamma လား မေးပါမယ်။ သင်ခန်းစာ ဘယ်နှခုအတွက်လဲ မေးရင် နံပါတ်ရိုက်ပါ (ဥပမာ ၁၀)။
        - ပြီးရင် "Picture number to type in the app: 001396" (ဒါမှမဟုတ် link အပြည့်) လို့ ပြပါမယ်။ ဒါကို မှတ်ထားပါ၊ အဆင့် ၃ မှာ သုံးပါမယ်။
        - တင်ပြီးသား ပုံတွေကို ကွန်ပျူတာထဲကနေ အလိုအလျောက် ဖျက်ပါတယ်။
        (ဒီအဆင့်က ပုံကိုပဲ တင်တာ၊ သင်ခန်းစာတွေကို app ထဲ ထည့်တာ မဟုတ်ပါဘူး။)


=== အဆင့် ၃။ Gemini Canvas ထဲမှာ သင်ခန်းစာ ထည့်၊ ထုတ်၊ save ===========================

 အရင် Canvas ထဲ ကုဒ်အသစ် ထည့်ပါ (တစ်ခါပဲ လိုတယ်) -
    canvas\Smartstudy-new.txt   ထဲက စာအကုန်ကို ကူးပြီး SmartStudy Canvas ထဲမှာ ကုဒ်အားလုံးကို အစားထိုး paste လုပ်ပါ။
    canvas\Abhidhamma-new.txt   ကိုလည်း Abhidhamma Canvas မှာ အတူတူလုပ်ပါ။

 --- SmartStudy ---
    ၁. Teacher အဖြစ် ဝင်၊ class ကို ရွေးပြီး  Bulk  tab ကို နှိပ်ပါ။
    ၂. "Load lessons file(s)" - ဆောင်းပါး .md ဖိုင်တွေ (တစ်ခါတည်း အကုန်ရွေးလို့ရ)၊ .txt၊ ဒါမှမဟုတ် .json ကို တင်ပါ။
    ၃. "Step 1" ကို နှိပ်ပါ။ သင်ခန်းစာအားလုံးရဲ့ အသက်အရွယ် ၄ ဆင့် စာတွေကို တစ်ခုပြီးတစ်ခု ရေးပေးပါမယ် (၁၀ စက္ကန့်စီ နားတယ်)။
       စာလုံးအရေအတွက် (၄၀-၈၀ / ၉၀-၁၇၀ / ၁၇၀-၃၀၀ / ၂၈၀-၄၅၀) ကို စစ်ပါတယ်။
    ၄. ခေါင်းစဉ်တွေကို သင်ကိုယ်တိုင် ရိုက်ပါ (Gemini အကြံပြုထားတာကို ပြင်လို့ရတယ်)။
    ၅. ပုံတင်ပြီးရင် အဆင့် ၂.၄ ရတဲ့ "first picture address" ကို ကွက်ထဲ ထည့်ပါ။ သင်ခန်းစာတိုင်း ပုံ ၅ ပုံစီ ဆက်တိုက် ရပါမယ်။
    ၆. "Step 2: save" ကို နှိပ်ပါ။ သင်ခန်းစာအားလုံး class ထဲ ဝင်ပါမယ်။
    ၇. "Step 3: format and make quizzes" ကို နှိပ်ပါ။ စာအလှစီတာနဲ့ Quiz ၄ ဆင့်စလုံးကို သင်ခန်းစာတစ်ခုပြီးတစ်ခု လုပ်ပါမယ်။ ပြီးတိုင်း save လုပ်ပါတယ်။
    - နားချိန်ကို ပြောင်းချင်ရင် "Rest between lessons" ကွက်မှာ ပြင်ပါ။ ရပ်ချင်ရင် "Stop after this lesson"။ နောက်မှ ခလုပ်ကို ပြန်နှိပ်ရင် ကျန်တာကို ဆက်လုပ်ပါတယ်။

 --- Abhidhamma ---
    ၁. Teacher အဖြစ် ဝင်ပါ (passcode 1)။ သင်ခန်းစာထည့်တဲ့ form အောက်မှာ  "Bulk lessons"  ခရမ်းရောင်ဘောင် ရှိပါတယ်။
    ၂. "1) Load lessons file(s)" (ဒါမှမဟုတ် အပေါ်က "Import Data / Lessons file") - .md၊ .txt၊ abhidhamma-articles-10.json တင်ပါ။
    ၃. ခေါင်းစဉ်တွေ စစ်ပါ။ ပုံနံပါတ်ကွက်ထဲ အဆင့် ၂.၄ ရတဲ့ နံပါတ် (ဥပမာ 001396) ထည့်ပါ။ "2) Save all" နှိပ်ပါ။
    ၄. "3) Make the 4 age versions for ALL lessons" ကို နှိပ်ပါ။ သင်ခန်းစာတိုင်း အသက်အရွယ် ၄ မျိုး (အင်္ဂလိပ်စာ၊ ဆွေးနွေးမေးခွန်း ၁၀ ခု၊ Quiz ၁၀ ခု) ကို
       တစ်ခုပြီးတစ်ခု လုပ်ပါမယ် (၁၀ စက္ကန့်စီ နားတယ်)။ အင်္ဂလိပ်စာ စာလုံးကန့်သတ်ချက် (၆၀-၁၂၀ / ၁၅၀-၂၅၀ / ၂၅၀-၃၅၀ / ၃၅၀-၅၀၀) ကို စစ်ပါတယ်။
       မပြည့်မီရင် Gemini ကို တစ်ခါ ပြန်ခိုင်းပါတယ်။
    ၅. ပြီးတဲ့အခါ အနက်ရောင်ကွက်ထဲမှာ  "OK ... English words"  လို့ ပေါ်ပါမယ်။  "check:"  ပါရင် ဘာမှားလဲ ပြောတာပါ။


=== အဆင့် ၃ ခွဲ။ Abhidhamma - Canvas မှာ လုပ်ပြီးသား ဗားရှင်းတွေကို app ရဲ့ class ထဲ ထည့်ပါ ===========

    Canvas မှာ အသက်အရွယ်ဗားရှင်း ထုတ်ပြီးရင် "Export Data" နဲ့ full_app_backup_....json ကို ဒေါင်းလုပ်ချပါ။
    ဒီဖိုင်ကို app ရဲ့ "Import Lessons Only" နဲ့ ထည့်ရင် ပုံမပါတဲ့ သင်ခန်းစာအသစ် ထပ်ဝင်ပြီး ၂ ခုစီ ဖြစ်နေပါလိမ့်မယ်။ အဲဒီအစား -
      lessons.bat မှာ  7  ကို နှိပ်ပါ (ဒါမှမဟုတ် merge-variants.bat ကို နှစ်ချက်နှိပ်ပါ)။
      1. Backup ဖိုင်နာမည် မေးရင် Enter (အသစ်ဆုံး backup ကို ယူပါတယ်)။
      2. ဘယ် class လဲ မေးရင် class နာမည်ရိုက်ပါ (ဥပမာ BASIC-ABHIDHAMMA-5)။
      3. ခေါင်းစဉ်တူတဲ့ သင်ခန်းစာတွေကို တွေ့ပြီး ဘာတွေ ထည့်မလဲ စာရင်းပြပါမယ်။ "Go ahead?" မှာ y ရိုက်ပါ။
      - မပြောင်းခင် အဲဒီသင်ခန်းစာတွေရဲ့ လက်ရှိအခြေအနေကို Downloads\lesson-backups ထဲ သိမ်းပေးပါတယ်။
      - သင်ခန်းစာတစ်ခုချင်းရဲ့ ပုံ ၅ ပုံကို အသက်အရွယ်ဗားရှင်းရဲ့ စာပိုဒ်တွေကြားမှာ ညီမျှစွာ ထည့်ပေးပါတယ်။
      - ကျောင်းသား data၊ ရမှတ်၊ တခြားသင်ခန်းစာတွေကို မထိပါဘူး။
      - အရင်စမ်းကြည့်ချင်ရင် lessons.bat မီနူးမသုံးဘဲ merge-variants.bat --dry ဆိုပြီး command မှာ ရိုက်ပါ (ဘာမှ မပြောင်းပါဘူး)။

=== အဆင့် ၄။ စစ်ပါ ================================================================

    - app ကို refresh လုပ်ပြီး သင်ခန်းစာအသစ်တွေ ပေါ်လားကြည့်ပါ။ ပုံ ၅ ပုံ ပါလား၊ Quiz ၁၀ ခု ရှိလား၊ စာ ဖတ်လို့ကောင်းလား။
    - မကောင်းတာတွေ့ရင် အဲဒီသင်ခန်းစာတစ်ခုကိုပဲ ပြန်ထုတ်လို့ရပါတယ်။


=== GitHub ပုံဆိုင် ပြည့်သွားရင် (အလိုအလျောက် ဖြစ်ပါတယ်) ==================================

    ပုံတွေကို GitHub ရဲ့ dhammaschool ဆိုင်မှာ သိမ်းပါတယ်။ သင် GitHub ကို ဝင်ကြည့်စရာ မလိုပါဘူး။ ပုံတင်တိုင်း (lessons.bat 4 ဒါမှမဟုတ် 6) ဒီစာ ပေါ်ပါမယ် -
        "GitHub picture repo: 395 pictures in 1 folder(s), about 160 MB (a folder holds up to 900 pictures)."
    - ဖိုဒါတစ်ခုမှာ ပုံ ၉၀၀ အထိ ထည့်ပါတယ်။ ပြည့်ရင် (ဖိုဒါအသစ် images-02၊ images-03 ... ကို) ကိုယ်တိုင် ဆောက်ပြီး ပုံအသစ်တွေကို အဲဒီထဲ ထည့်ပါတယ်။
      ပုံနံပါတ်တွေက ဖိုဒါအားလုံးကို ဖြတ်ပြီး ဆက်ရေတွက်ပါတယ် (001396 ၊ 001397 ...)။ ပုံလင့်ကို သင်ခန်းစာထဲ အလိုအလျောက် မှန်အောင် ထည့်ပေးပါတယ်။
      ရှိပြီးသား သင်ခန်းစာတွေရဲ့ ပုံလင့်တွေ ဘာမှ မပြောင်းပါဘူး။
    - ဆိုင်တစ်ခုလုံး ၇၀၀ MB ရောက်ရင် "The picture repo is ... MB" ဆိုတဲ့ သတိပေးစာ ပေါ်ပါမယ်။ ၉၅၀ MB ရောက်ရင် ဆက်မတင်တော့ဘဲ ရပ်ပါတယ်
      (GitHub က ဆိုင်တစ်ခုကို ၁ GB အောက် ထားခိုင်းလို့ပါ)။ အဲဒီအခါ ပုံဆိုင်အသစ် လိုပါတယ် - ကျွန်တော် (Claude) ကို ပြောပါ။
    - လက်ရှိ ၁၆၀ MB၊ ပုံ ၃၉၅ ပုံပါ။ ပုံ တစ်ပုံ ပျမ်းမျှ ၀.၄ MB ဆိုတော့ သင်ခန်းစာအသစ် ၂၅၀ လောက် ထပ်ထည့်ရင် သတိပေးစာ စပေါ်ပါလိမ့်မယ်။

=== ပြဿနာ ဖြစ်ရင် ===================================================================

    Gemini က "ခဏစောင့်ပါ" လို့ပြောတာ (429)  - ကုဒ်က ၁၀၊ ၂၀၊ ၃၀ စက္ကန့် စောင့်ပြီး ကြိုးစားပါတယ်။ မရရင် ခဏနားပြီး ခလုပ်ကို ပြန်နှိပ်ပါ (ပြီးသားတွေ ပျက်မသွားပါ)။
    "FAILED" ပေါ်တာ                           - အဲဒီခလုပ်ကို ပြန်နှိပ်ပါ၊ မပြီးသေးတဲ့ သင်ခန်းစာတွေကိုပဲ ထပ်လုပ်ပါတယ်။
    ဖိုင်ကို နားမလည်ဘူး / "No lessons found" - ဆောင်းပါးတစ်ပုဒ်စီ "# ခေါင်းစဉ်" ဒါမှမဟုတ် "ဆောင်းပါး (၁) - ..." နဲ့ စရဲ့လား စစ်ပါ။ sample-*.txt တွေနဲ့ ယှဉ်ကြည့်ပါ။
    ဘာမှ မရဘူး                                - ဖန်သားပြင်စာကို ကူးပြီး ကျွန်တော်ဆီ ပို့ပါ။

=== သိထားရန် (ကျွန်တော် မသေချာတာ) ==================================================

    - Canvas ရဲ့ Abhidhamma ကုဒ်မှာ class (အတန်း) မရှိပါဘူး။ လက်ရှိ app ကတော့ class နဲ့ပါ။ Canvas မှာ ထုတ်ပြီးသား သင်ခန်းစာတွေကို app ထဲ
      ရွှေ့တာ (Export Data -> app ထဲ Import) ကို သင်ခါတိုင်းလုပ်တဲ့နည်းအတိုင်း လုပ်ပါ။ ကိုက်မကိုက် ကျွန်တော့်ကို ပြောပြပါ။
    - Canvas နဲ့ ပုံလင့်ရဲ့ GitHub ဆိုင်ကလည်း ကွာနိုင်ပါတယ် (Abhidhamma Canvas က dhamma4 repo ကို ကြည့်တယ်၊ ပုံ upload က dhammaschool repo)။
      ပုံမပေါ်ရင် ကျွန်တော့်ကို ပြောပါ။
