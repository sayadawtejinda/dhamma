Preposition game (Burmese Learning Games, Part 4) -- recordings still needed
==========================================================================

Put each recording here as an .mp3 with EXACTLY this file name (a short clip, one phrase,
about 1-2 seconds, no long silence at the start or end). A clip that is missing is simply
skipped: the game still works, it just stays silent for that phrase.

PLACE WORDS (the three answers the student chooses from)
  on.mp3         အပေါ်မှာ      (on / above)
  under.mp3      အောက်မှာ      (under)
  inside.mp3     ထဲမှာ         (in)
  beside.mp3     ဘေးမှာ        (beside)
  front.mp3      ရှေ့မှာ        (in front of)
  behind.mp3     နောက်မှာ      (behind)
  between.mp3    ကြားမှာ       (between)

QUESTION ENDINGS
  q_where.mp3    ဘယ်မှာ ရှိသလဲ       ("<object> ... where is it?" -- the object's own name is played
                                    first from the existing audio, e.g. ပန်းသီး + ဘယ်မှာ ရှိသလဲ)
  q_what_in.mp3  ထဲမှာ ဘာရှိသလဲ       ("<box> ... what is in it?" -- played after the word ပုံး)
