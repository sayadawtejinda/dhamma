သင်ခန်းစာအသစ် ထည့်နည်း  (SmartStudy နဲ့ Abhidhamma) — တစ်နေရာတည်း၊ အဆင့်ဆင့်
================================================================================

ဒီ project folder ထဲက  lessons.bat  ကို double-click လုပ်ပါ။ မီနူးပေါ်လာပါမယ်။ အောက်က အဆင့်တွေကို အစဉ်လိုက် လုပ်ရုံပါပဲ။
(ဒီစာတမ်း (HOW_TO_ADD_LESSONS.txt) ကို lessons.bat ထဲက "8" နဲ့လည်း ဖွင့်လို့ရပါတယ်။)

ကိုယ်မှာ ရှိရမယ့်ဟာ (တစ်ခါပဲ စီစဉ်ထားရင် ရပါတယ်)
  - Node.js (ဆရာ့ကွန်ပျူတာမှာ ရှိပြီးသား)
  - Gemini key: scripts\gemini-key.txt ထဲမှာ တစ်ကြောင်းတည်း ရေးထားရမယ် (GitHub ပေါ် မတင်ပါ)
  - ပုံတွေအတွက် GitHub repo  sayadawtejinda/dhammaschool  ကို ပထမအကြိမ် run တဲ့အခါ ကွန်ပျူတာထဲ ကော်ပီ အလိုအလျောက် ယူပါမယ် (git ဝင်ထားရမယ်)

--------------------------------------------------------------------------------
အဓိကလမ်းကြောင်း (နှစ်ခုလုံး အတူတူ)

  ဇာတ်လမ်း notebook (.txt)  ──►  [အဆင့် 1] lesson ဖိုင် (.json) ထုတ်
  Gemini ပုံအချပ်တွေ         ──►  [အဆင့် 2] ပုံတစ်ပုံချင်း ခွဲ
                                  [အဆင့် 3] app ထဲ ထည့် (ပုံတင် + lesson ထည့်)
                                  [အဆင့် 4] app မှာ စစ်

အဆင့် 1 — Gemini နဲ့ lesson ဖိုင်ထုတ်       (lessons.bat → 1  /  make-lessons.bat)

  မေးတာတွေ:
    "1 = SmartStudy lessons, 2 = Abhidhamma lessons"  →  1 သို့ 2
    "Stories file name"  →  notebook .txt ဖိုင်နာမည် (Downloads / Desktop / Documents ထဲမှာ ရှိရင် ရှာတွေ့ပါမယ်)
    "Save the lessons as"  →  Enter (အလိုအလျောက် နာမည်ပေးပါမယ်)  ဥပမာ  lessons-2026-10-27.json
  ဘာထွက်လဲ: SmartStudy = အသက်အရွယ် ၄ ဆင့် (storyteller, explorer, adventurer, voyager)၊ ခေါင်းစဉ်၊ quiz ၁၀ ခု
            Abhidhamma = မြန်မာ lesson ဖိုင်
  မှတ်ချက်: Gemini က တစ်မိနစ်မှာ တောင်းလို့ရတာ နည်းလို့ လေးပါတယ်။ ဖွင့်ထားခဲ့လို့ရတယ်။ ရပ်သွားရင် နာမည်တူနဲ့ ထပ် run
            ရင် ပြီးသားနောက်ကနေ ဆက်လုပ်ပါမယ်။
  ဒီအဆင့်ကို ကိုယ်တိုင်ရေးထားတဲ့ lesson ဖိုင်ရှိရင် ကျော်နိုင်ပါတယ်။

  ဆောင်းပါး (.md) တွေကို သုံးချင်ရင် (Google NotebookLM က ထုတ်ပေးတာ)
    "Stories file name" မှာ  article-*.md  လို့ ရိုက်ပါ (ဖိုင်အကုန် တစ်ခါတည်း)၊ ဒါမှမဟုတ် ဖိုင်တစ်ခုချင်း၊ ကော်မာခြားပြီး ဖိုင်များ။
    ဆောင်းပါး ၁ ပုဒ် = သင်ခန်းစာ ၁ ခု။ ခေါင်းစဉ်ကို  # စာကြောင်းကနေ ယူပါတယ် ("ဆောင်းပါး (၁) -" ကို ဖြုတ်ပါတယ်)။
    ဖိုင်နာမည်ထဲက နံပါတ်အစဉ် (article-2 က article-10 ရှေ့) အတိုင်း စီပါတယ်။ အရင်ပုံစံ (=== နဲ့ 📖) ကိုလည်း ဆက်သုံးလို့ရပါတယ်။
  Abhidhamma မှာ "Make a picture plan?" မေးရင် y ရွေးပါ။ သင်ခန်းစာတစ်ခုချင်းအတွက် ပုံ ၅ ပုံရဲ့ prompt စာရင်း (L01-P1 ... L01-P5) နဲ့
    Downloads\abhidhamma-...-picture-plan.txt ထွက်ပါမယ်။ ပုံတွေကို အစီအစဉ်မှန်စေဖို့ အဆင့် 2 အစား  lessons.bat → 6  (name-pictures.bat) သုံးပါ။

အဆင့် 2 — ပုံတွေ ခွဲ                       (lessons.bat → 2  /  split-sheets.bat)

  Gemini ကနေ ရတဲ့ ပုံအချပ် (ပုံ ၆ ပုံပါတဲ့ တစ်ချပ်) တွေကို တစ်ပုံချင်း ခွဲပါတယ်။
  - အချပ်တွေက  Pictures\Screenshots  ဒါမှမဟုတ်  Downloads  ထဲမှာ  Gemini_Generated... နာမည်နဲ့ ရှိနေရမယ်
  - ပုံ ၆ ပုံထဲက မလိုတဲ့ ၁ ပုံကို နံပါတ်ရိုက်ပြီး ဖယ်ပါ (ပုံ ၅ ပုံပဲ ရှိရင် Enter)
  - ခွဲပြီး Downloads\lesson-pictures ထဲ ဇာတ်လမ်းအစဉ်လိုက် ထည့်ပေးပါမယ်။ မူရင်းအချပ်ကို  Screenshots\sheets  ထဲ ရွှေ့ထားပြီး မဖျက်ပါ
  - ကိုယ်တိုင်ရိုက်ထားတဲ့ screenshot ပုံတွေ ရှိရင် ဒီအဆင့်ကို ကျော်ပါ

  ပုံတွေကို ကိုယ်တိုင် ခွဲထားရင် (screenshot / ဖြတ်ထားတာ):
    Downloads\lesson-pictures ထဲမှာ သင်ခန်းစာနံပါတ်နဲ့ folder ဆောက်ပြီး (ဥပမာ  04  ဒါမှမဟုတ်  L04  ဒါမှမဟုတ်  lesson 4)
    ပုံ ၅ ပုံကို အဲဒီထဲ ထည့်ပါ။ ဖိုင်နာမည်အစဉ်အတိုင်း (screenshot နာမည်မှာ အချိန်ပါလို့ ရိုက်တဲ့အစဉ်) ပထမပုံက P1 ပါ။
    add-lessons က ဒါကို နားလည်ပါတယ်။ ချပ်ခွဲထားတာနဲ့ ကိုယ်တိုင်ခွဲထားတာကို ရောနှောသုံးလို့ရပါတယ်။ ပုံမရှိတဲ့ သင်ခန်းစာကိုတော့
    folder မလုပ်ထားဘူးဆိုရင် အရင်လိုပဲ ပုံလွတ်တွေကို အဟောင်းဆုံးကစယူပါတယ်။
  ဘယ်ဟာကို နှိပ်ရမလဲ:
    - Gemini က ပုံ ၆ ပုံပါတဲ့ ချပ်တစ်ချပ် ထုတ်ပေးရင်  →  lessons.bat → 2 (split-sheets)။ ချပ်ဖိုင်နာမည်ကို သင်ခန်းစာနံပါတ်နဲ့ ပေးထားရင်
      (03.jpg) သူ့အလိုလို သိပါတယ်။ မပေးထားရင် "ဘယ်သင်ခန်းစာလဲ" မေးပါတယ်။ ပုံတွေကို L03-P1...P5 နာမည်နဲ့ သိမ်းပေးလို့ အစီအစဉ်မှန်ပါတယ်။
    - ပုံတစ်ပုံချင်း ထုတ်ရင်  →  lessons.bat → 3 (name-pictures)။ အောက်က ရှင်းပြချက်အတိုင်း။
  ပုံကို တစ်ပုံချင်း ထုတ်တဲ့နည်း (picture plan နဲ့ — အစီအစဉ်မမှားပါ)   (lessons.bat → 6  /  name-pictures.bat)
    - plan ဖိုင်ကို အလိုအလျောက်ယူပြီး "သင်ခန်းစာ ၃၊ ပုံ ၂" ဆိုပြီး လုပ်ရမယ့်ပုံနဲ့ prompt ကို ပြပါတယ်။
    - Gemini မှာ ပုံထုတ်ပြီး Downloads (ဒါမှမဟုတ် Screenshots) ထဲ သိမ်းပါ။ Enter နှိပ်ရင် အသစ်ဆုံးပုံကို  L03-P2.png  နာမည်ပေးပြီး
      Downloads\lesson-pictures ထဲ ထည့်ပေးပါတယ်။ ပုံမကြိုက်ရင် ပိုကောင်းတာထုတ်ပြီး  r  ရိုက် (အရင်ပုံကို အစားထိုး)၊  s = ကျော်၊  q = ရပ်။
    - ပြီးသား slot တွေကို ထပ်မေးမှာမဟုတ်လို့ ရပ်ပြီး နောက်မှ ဆက်လုပ်လို့ရပါတယ်။
    - ပုံတွေ အလုံးအရင်ထုတ်ထားပြီးရင် ဘယ်နှပုံ စောင့်နေလဲ ဆိုတာ ထည့်ပါ (အသစ်ဆုံးကနေ အဟောင်းဆုံးအစဉ်နဲ့ ယူပါမယ်)။

အဆင့် 3 — app ထဲ ထည့်                      (lessons.bat → 6  /  add-lessons.bat)

  အရင်ဆုံး စစ်ကြည့်ချင်ရင်  lessons.bat → 5 (look first) — ဘာမှ မပြောင်းဘဲ ကြည့်ရုံ။
  မေးတာတွေ:
    "1 = SmartStudy, 2 = Abhidhamma"
    SmartStudy: "Class id" — ရှိပြီးသား class id ရိုက်ရင် အဲဒီထဲ ထပ်ထည့်၊ အသစ်ရိုက်ရင် class အသစ်ဖွင့်
    Abhidhamma: "old or new? (o/n)" ရွေးပြီး class id
    "Lessons file name" — အဆင့် 1 က .json ဖိုင်နာမည်
    Summary ပြပါမယ် → "Go ahead? (y/n)" → y
  အလိုအလျောက် လုပ်ပေးတာ:
    1. Downloads\lesson-pictures ထဲက ပုံတွေကို အဟောင်းဆုံးကနေ သုံးပြီး ဂဏန်းဆက်ပြီး နာမည်ပြောင်း (SmartStudy ၄ လုံး၊ Abhidhamma ၆ လုံး)
    2. GitHub  sayadawtejinda/dhammaschool  ကို တင်
    3. lesson ထဲက ပုံလင့်တွေ ထည့်ပြီး lesson တွေကို SmartStudy / Abhidhamma ထဲ ထည့်
    4. တင်ပြီး အဆင်ပြေမှ သုံးပြီးသား screenshot တွေကို ကွန်ပျူတာထဲက ဖျက် (အကုန်ပြီးမှ)
    5. Abhidhamma ဆိုရင် "age versions ၄ မျိုး Gemini နဲ့ ထုတ်မလား" မေးမယ် (ပျမ်းမျှ lesson တစ်ခုကို ၃ မိနစ်၊ y ရိုက်) — မအောင်တာရှိရင်
       app ထဲမှာ အဲဒီ lesson ရဲ့ Generate ခလုတ်နဲ့ ဆက်ထုတ်လို့ရတယ်

  picture plan သုံးထားရင် add-lessons က ပုံတွေကို  L01-P1...  နာမည်အတိုင်း စီပါတယ် (ဖိုင်အချိန်ကို မကြည့်ပါ)။ သင်ခန်းစာတစ်ခုချင်း
  ဘယ်ပုံ ရှိ/မရှိ စာရင်းပြပြီး ပုံပါတာမပြည့်ရင် ဘာမှမပြောင်းဘဲ ရပ်ပါတယ်။
  ပုံ ၅ ပုံကို lesson တစ်ခုက လိုပါတယ်။ ပုံနည်းနေရင် "ပုံ N ပုံ ထပ်လိုတယ်" လို့ ပြောပြီး ရပ်ပါမယ် (ဘာမှ မပြောင်းသေးပါ)။

အဆင့် 4 — app မှာ စစ်

  - SmartStudy / Abhidhamma ကို refresh လုပ်ပြီး lesson အသစ် ပေါ်လား ကြည့်
  - ကျောင်းသားတွေ မြင်ဖို့ GitHub မှာ class ဖိုင်အသစ် တည်ဆောက်ရပါတယ်။ ဒါကို နာရီတိုင်း အလိုအလျောက် စစ်ပြီး လိုရင် ဆောက်ပေးပါတယ်
    (ဆရာ ဘာမှ မလုပ်ရ)။ lesson ထည့်ပြီး ~၁ နာရီအတွင်း ကျောင်းသားတွေ မြင်ရမယ်။
    ချက်ချင်းမြင်ချင်ရင်: GitHub → Actions → "Class snapshots" → Run workflow
  - ဒီအတောအတွင်း ကျောင်းသားတွေက Firebase ကနေ တိုက်ရိုက်ဖတ်ပြီး မြင်ရတာမို့ မမြင်ရဘူး မဖြစ်ပါ။
