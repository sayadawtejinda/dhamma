# ဘုရားခန်း Meditation စာသားများ ထည့်နည်း

Meditation တစ်ခုချင်းစီက ဒီဖိုဒါ (`src/meditations`) ထဲက စာဖိုင် (.txt) တစ်ခုစီပါ။ ဖိုင်အသစ်တစ်ခု ထည့်လိုက်ရုံနဲ့ ဘုရားခန်းထဲက drop list မှာ ပေါ်လာပါတယ်။ ကုဒ် မပြင်ရပါဘူး။

## အဆင်သင့်ပြင်ထားတဲ့ ဖိုင်များ

`Meditation 4.txt` ကနေ `Meditation 10.txt` အထိ ထိပ်ပိုင်း (title / audio) အဆင်သင့် ပြင်ထားပြီးသားပါ။ ဖိုင်ကိုဖွင့်ပြီး အသံဖိုင်နာမည် (ရှိရင်) ရေးကာ စာသား paste လုပ်ရုံပါပဲ။ စာသားမထည့်သေးတဲ့ဖိုင်တွေက drop list မှာ မပေါ်ပါဘူး။ ၁၀ ခုထက်ပိုလိုရင် `Meditation 11.txt` စသည်ဖြင့် ဖိုင်ကူးပြီး နံပါတ်ပြောင်းပါ။

`#` နဲ့ စတဲ့ စာကြောင်းက မှတ်စုပါ၊ ဘာမှ မလုပ်ပါဘူး။

## အဆင့်များ

1. ဒီဖိုဒါထဲမှာ `Meditation 4.txt` လို နာမည်နဲ့ စာဖိုင်အသစ်လုပ်ပါ။ (Notepad နဲ့ ရပါတယ်၊ သိမ်းတဲ့အခါ UTF-8 ရွေးပါ။)
2. ဖိုင်ထဲ စာတွေကို ထည့်ပါ။ အောက်က ပုံစံအတိုင်းပါ။
3. အသံဖိုင်ရှိရင် `audio` ဖိုဒါထဲ ထည့်ပြီး ဖိုင်နာမည်ကို ဖိုင်ထိပ်မှာ ရေးပါ။
4. ပြီးရင် Claude ကို "Meditation 4 ထည့်ပြီးပြီ၊ push လုပ်ပေးပါ" လို့ ပြောပါ။

## ဖိုင်ပုံစံ

```
title: Meditation 4
audio-en: Ryan meditation 4.m4a
audio-my: Ryan meditation 4 Myanmar.mp3

၁။ မြန်မာစာကြောင်း။

English line.

၂။ နောက်မြန်မာစာကြောင်း။

Next English line.
```

- `title:` — drop list မှာ ပြမယ့်နာမည်။ မရေးရင် ဖိုင်နာမည်ကို သုံးပါတယ်။
- `audio-en:` — အင်္ဂလိပ်အသံဖိုင်နာမည်။ မရှိသေးရင် ဒီစာကြောင်းကို မရေးပါနဲ့။ နောက်မှ ထပ်ထည့်လို့ရပါတယ်။
- `audio-my:` — မြန်မာအသံဖိုင်နာမည်။ ဒါလည်း မရှိသေးရင် မရေးပါနဲ့။
- အသံဖိုင်က mp3၊ m4a စတာ ဘာဖြစ်ဖြစ် ရပါတယ်။ နာမည်ရဲ့ အဆုံးက `.mp3` မရေးလည်း ရပါတယ်။
- စာသားက **မြန်မာတစ်ကြောင်း၊ အင်္ဂလိပ်တစ်ကြောင်း** အတွဲလိုက် ဖြစ်ရပါမယ်။ စာကြောင်းကြားမှာ လပ်ကြောင်း ထည့်လည်းရ၊ မထည့်လည်းရပါတယ်။ အတွဲ ၃၀ လောက် (အသံ ၅ မိနစ်စာ)။
- စာကြောင်းရဲ့ အရှေ့က နံပါတ် (`၁။`၊ `12.`) ပါနေလည်း အလိုအလျောက် ဖယ်ပေးပါတယ်။
- အသံဖိုင်ကို ၁၀ မိနစ်နဲ့ အထက် ထိုင်တဲ့သူကိုပဲ ဖွင့်ပေးပါတယ်။ ၅ မိနစ်ထိုင်ရင် စာသားပဲ ပြပါတယ်။
- Drop list မှာ ဖိုင်နာမည်အလိုက် အစဉ်လိုက် ပေါ်ပါတယ် (Meditation 2 က Meditation 10 ရှေ့မှာ)။ ပထမဆုံးဖိုင်ကို အစမှာ ပြပါတယ်။
